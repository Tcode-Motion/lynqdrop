Frequently Asked Questions

Everything you need to know about LynqDrop's privacy and networking.

Are my files stored on LynqDrop's servers? +

No. LynqDrop enforces a strict zero server storage policy. Files transfer directly between sender and receiver devices through encrypted WebRTC DataChannels or direct TCP/TLS sockets. Our signaling servers only coordinate peer handshakes and never touch or store file content.

Is there any file size limit in the browser? +

No. By streaming files in 64 KiB chunks using threshold backpressure flow control and direct-to-disk File System Access / OPFS sinks, LynqDrop can transfer large multi-gigabyte files without crashing your browser or exhausting memory.

Can I share files between different networks and countries? +

Yes. When devices are not on the same local Wi-Fi, WebRTC uses STUN and automatic DTLS-encrypted TURN relay traversal to establish direct peer connections worldwide across NATs and firewalls.
